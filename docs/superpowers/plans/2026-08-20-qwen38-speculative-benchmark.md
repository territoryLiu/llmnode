# Qwen3.8 投机解码对照实验实施计划

1. 核验 GPU、镜像版本、CLI 参数和模型下载完整性。
2. 为 vLLM 编排补独立 draft 模型只读挂载，保持旧 profile 兼容。
3. 为 streaming benchmark 补并发批次和聚合 output tok/s。
4. 新建六个互不覆盖的实验 profile，并验证渲染出的容器参数。
5. 按候选顺序逐个启动、健康检查、warmup、运行 64K+800 的并发 1/2/3 矩阵。
6. 保存 server log、版本、GPU、命令和 summary；失败项保存明确原因。
7. 汇总性能、容量、稳定性与接受指标，形成部署建议并回流知识库。
8. 运行相关代码测试、文档引用检查和最终完成审计，停止实验服务。
